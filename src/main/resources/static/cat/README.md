# AgniPress Cat Assets

Place the six production mascot PNG files in this directory with these exact names:

- `01-idle-welcome.png`
- `02-name-filled-pointing.png`
- `03-error-unimpressed.png`
- `04-email-focus.png`
- `05-ready-to-submit.png`
- `06-success.png`

The registration page loads them from `/cat/<filename>`.
