# AgniPress Cat Voice Pack

Optional production voice files for the registration mascot. Add these exact MP3 filenames to this directory:

- `intro.mp3`
- `name-success.mp3`
- `username-success.mp3`
- `username-error.mp3`
- `email-intro.mp3`
- `ready.mp3`
- `success.mp3`
- `meow.mp3`

The registration guide falls back to browser speech synthesis if a voice file is missing.
